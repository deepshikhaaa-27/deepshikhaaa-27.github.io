Oracle Redwood Design System
How this portfolio follows Oracle's design philosophy

Redwood is Oracle's human-centered design system for enterprise apps. This portfolio uses its visual language to show familiarity with Oracle Cloud UI and UX.

Principles applied
Clarity first
Clear hierarchy: section labels, titles, short descriptions.
Consistent scale
Spacing, radius and type sizes follow one scale.
Purposeful color
Redwood red is for actions and emphasis only.
Human-centered
Tabs and cards keep each view short and scannable.
