# My Portfolio

Redwood-style single-page portfolio (tabs: Home, Experience, Projects, Skills, Articles, Contact).

## Edit your details
Open `js/data.js` and change the values. Nothing else needs editing.
Photo: add `assets/photo.jpg` and set `photo: "assets/photo.jpg"`.

## Publish on GitHub Pages
1. Create a repo named `YOUR-USERNAME.github.io` (public).
2. Upload everything in this folder (keep the folders).
3. Settings > Pages > Source: Deploy from a branch > `main` / root > Save.
4. Open https://YOUR-USERNAME.github.io after ~1 minute.
